# Contributing

See [the contribution guide](docs/contributing.md) for the development and documentation workflow, review expectations, and local preview instructions.

Use a focused branch, describe what changed and how you verified it, and keep discussion respectful. Contributions are covered by this repository's [MIT license](LICENSE).

For documentation changes, install `requirements-docs.txt` in a Python virtual environment and run:

```bash
zensical build --strict
```
